# Rope Tangle has moved

The game now lives at https://rope-tangle.github.io/ (repo [rope-tangle/rope-tangle.github.io](https://github.com/rope-tangle/rope-tangle.github.io)).

This repo only keeps the old address working: every page under `adrianschmidt.github.io/rope-tangle/` redirects to the same path on the new site, and `sw.js` (plus `dev/sw.js` for old previews) replaces the old offline service worker with one that clears its cache, unregisters itself and reloads the page.
